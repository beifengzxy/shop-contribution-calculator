# 单品利润与退货贡献测算

本地历史产物已补齐，入口为本地文件 `archive-local/README.md`。原始与历版ZIP、AI角色试填、制作和核验中间文件、招募记录与生成原图保留在 `archive-local/`，来源和SHA-256均有清单。该目录及销售内部记录仅用于本地归档，已排除Git提交，不包含在GitHub下载中。

用 Excel/WPS 归集同商品、售后已结束的一批订单，比较售价、正常订单贡献与退货损耗。当前版本 **v0.3**。

**项目仍处于试用验证阶段。案例的商品、24笔订单、费率和角色反馈均由 AI 构造，不能作为真实经营效果、真人满意度或支付意愿的证据。**

## 开始使用

1. 阅读 [开始试用](docs/开始试用.md) 和 [两页说明](docs/两页使用说明.pdf)。
2. 下载 [未填写的试用模板](templates/单品利润与退货测算样品.xlsx)，保存自己的副本，在 Excel/WPS 中打开。
3. 填写「填表前归集」黄色输入区，处理缺项提示，再把结果只粘贴数值到「场景测算」。归集变动后需要重新粘贴。
4. 对照 [模拟试填汇总](examples/merchant-v0.3/试填汇总.md) 与 [已填写案例](examples/merchant-v0.3/填写结果.xlsx)。

“未填写”指供用户录入的试用模板；其中保留独立示例页和原有提示。四张表均无密码保护，黄色区可编辑。

## 本工具计算什么

模型只包括正常完成和退货两类订单；未发货取消、仅退款、换货等收入费用另算。结果为订单贡献，尚需另算固定成本、税、自有劳动与现金流，不能直接解释成店铺净利润。

广告归因、实际平台费、退回商品可回收成本需要店主提供依据；未知数据先留空。模板不会导入平台账单或自动判断归因。更改价格时相关费用也需要同步核对。

## 模拟案例

模拟保温杯批次有24笔记录，其中18正常、3退货进入模型，共21笔。89元原价的模型内整批贡献为489.53元；在数量、结构与其他费用假设不变时，84元方案为404.18元。价格变化引起的真实销量、广告和退货率尚未验证。

[假设说明](examples/merchant-v0.3/虚构批次及假设.md)、[逐笔CSV](examples/merchant-v0.3/独立虚构订单.csv)、[模拟反馈](examples/merchant-v0.3/模拟反馈.md) 均可直接阅读。

## 自行复核

需要 Python 3.10 或更高版本，只用标准库，无需安装依赖。在项目目录运行：

```sh
python3 scripts/verify_workbook.py
python3 scripts/reconcile_orders.py
```

第一条复核工作簿结构、公式保留、保护、输入范围、账单归集和场景结果，共43项；第二条逐单重算24笔CSV并核对归集、舍入与保护。任一核对失败返回非零退出码。当前运行报告写入 `reports/`；包内原始复核JSON作为历史证据保留。

脚本读取工作簿中保存的公式缓存值，并使用 Decimal 独立核对账单与关键结果；不会驱动 Excel/WPS 重算，也不证明全部输入组合正确或所有软件兼容。不要用 `python -O` 运行（部分检查使用 assert）。
